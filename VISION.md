# NoBS vision

**Saving corporate from corporate BS.**

Modern work wastes attention through constant pings and meetings spent discovering context. NoBS changes the primitive from “message a person” to “express an intent,” while preserving the moments only humans can own.

> Ask my context, not my attention.

> Agents do coordination. Humans do judgment.

## Less Ping

A model-free preflight resolves the responsible employee/project/team/policy scope. Permission-aware retrieval supplies only evidence the requester may access, one bounded Gemini synthesizer answers, and the reply appears in the native Mattermost thread. `--direct` remains human-only and consumes no model budget. Restricted requests stop before retrieval; poisoned content is quarantined.

The delegate directory is an organizational model, not a fleet of processes. It records representation, scope, relationships, evidence boundaries, availability, and authority context.

## Less Meeting

An eligible meeting becomes a durable governed mission. A Gemini 3.5 controller creates bounded assignments; Work Graph and Policy Evidence agents execute concurrently; a deterministic critic validates claims; a Gemini 3.5 resolution agent classifies the agenda; deterministic policy decides whether a human checkpoint is required.

If evidence resolves every item, NoBS can recommend cancellation. If only human authority remains, it recommends a shorter meeting. Recommendations cannot self-execute. The same mission pauses for the organizer, and only a separate idempotent executor can apply an approved action to a real Calendar event.

## Product foundation

Mattermost/PostgreSQL remains the mature authority for identity, collaboration, and realtime delivery. Firestore owns mission/governance state. Pub/Sub handles repeatable asynchronous delivery. Agent Registry catalogs executable programs. Agent Engine Sessions stores ADK context; Memory Bank stores preferences only. Model Armor and deterministic evidence authorization surround every model invocation.

Visible product text says NoBS. Internal plugin IDs, environment variables, collections, and `noping-*` Google Cloud resources remain for safe compatibility.

## Principles

1. Collaboration stays primary; agent views explain work rather than replace conversation.
2. Identity, access, policy, and authority are deterministic and precede models.
3. Agents are used for open-ended knowledge work; deterministic code owns invariants and side effects.
4. Runtime views expose steps, evidence references, timing, gates, and outcomes—not hidden reasoning.
5. Human approval resumes the same durable mission.
6. External effects are typed, least-privilege, stale-safe, idempotent, and verified.
7. Confirmed decisions and personal preferences remain separate by authority.
8. Claims, integrations, model IDs, and platform services must match deployed reality.
9. Cost and failure boundaries stay explicit: scale to zero, max one, bounded calls/tokens, existing $25 guard.

## Success

The primary metric is **human attention saved without reducing evidence quality or violating authority**. Supporting measures are interruptions avoided, meeting minutes returned, agenda items resolved, checkpoint count, unsafe evidence blocked, duplicate effects prevented, completion latency, token use, and cost per completed mission.

## Out of scope

Unrestricted swarms, model-based authorization/approval, generic shell/SQL/HTTP tools, autonomous compensation/legal/employment/security decisions, direct model Calendar access, one service per agent/delegate, GKE/service mesh/graph/vector databases without measured need, multi-region hackathon infrastructure, or any weakening of the $25 guard.
